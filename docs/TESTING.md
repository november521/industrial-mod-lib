## 下次实机复验

1. 新建测试世界，导入三个当前验收包。在日志核对行为包均已加载，发电机、电池、导管与储罐可以放置。记录游戏版本、工作台版本和三份包的版本。
2. 将发电机放在空电池上方。在聊天框用 `imlfe charge X Y Z` 触发发电机，用 `imlfe read X Y Z` 读取电池。两条命令分别填对应方块坐标，无需斜杠。空电池第一次应收到 200 FE，充至 1000 FE 后返回 0。移开电池或从侧面供电时，电池库存应保持原值。保存重进后再核对 FE。
3. 同一存档复跑一次物品和流体示例。记下库存，离开到区块卸载，再返回重新查询和操作，确认储量恢复且新查询可用。若要确认卸载期间查询返回空，需从仍加载的服务端测试脚本查询原坐标，单靠离开再回来只能确认恢复。
4. 复跑[装有物品的潜影盒搬运](../examples/README.md#木桶与潜影盒验收)。重新放下盒子后核对内部槽位、种类和数量。

实测记录至少写明版本、场景、预期、实际和相关服务端日志。若某项未执行，保留待验收状态。
