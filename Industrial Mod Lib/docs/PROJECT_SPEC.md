# 工业模组通用前置库

## 首版交付

- 一个可独立加载的网易《我的世界》基岩版 ModSDK 前置行为包，正式显示名为「工业模组通用前置库」。能量单位沿用 FE。
- 一份面向第三方开发者的公开 API 文档，包含前置安装、初始化顺序、版本识别、端口注册、查询、模拟和实际存取的示例。
- 两个分别打包、附源码且可直接加载的开发示例。示例 A 提供资源源头，示例 B 提供接收设备和简单导管。两者通过文档中的公开接口接入，开发者无需修改前置库。

末影接口另立项目。首版示例用于开发和验收，正式贴图、生存配方和操作界面留给玩法组件。

## 公开 API

服务端提供统一的方块端口注册与查询入口。查询条件为维度、坐标、目标方块面和能力类型。端口根据方块面提供对应权限。目标无相应能力或当前不可用时，查询返回空。文档需说明端口有效期以及方块替换、区块卸载后的重新查询规则。

| 能力 | 首版覆盖 | 操作 |
| --- | --- | --- |
| 能量 | 发电机、电池和耗电机器等方块设备 | 查询储量和容量，模拟或实际充入、取出整数 FE，返回对应的可操作量或实际操作量 |
| 物品 | 主动接入的自定义设备、原版普通单箱与双箱 | 查询槽位和物品，模拟或实际插入、抽取。插入返回余量，抽取返回对应的物品堆。保留物品自定义数据 |
| 流体 | 接入库的机器和储罐，以水、岩浆验收 | 查询流体类型、储量和容量，模拟或实际注入、抽取。采用统一流体 ID 和计量单位 |

模拟操作只计算当前可执行的结果，无库存副作用，也无预留效果。调用方用实际操作返回值结算。原版箱子与自定义机器共用物品端口。双箱从两半或多个面接入时，共享槽位只计算一次，各面仍可有各自的访问权限。

首版能量范围为方块设备，流体范围为设备间传输，原版物品容器范围为普通单箱和双箱。可充电物品、原版桶、世界液体交互、木桶、潜影盒和熔炉留待后续评估。

## 批量搬运示例

一对多、多对一和多对多在示例组件中实现。公开 API 范围为端口注册、查询和存取，批量搬运执行器在示例中验证。

- 按管网调度，同一轮按需读取端口，复用已读取的库存状态。以实际库存和槽位为单位分配额度，多个来源共享目标剩余容量。
- 按过滤、优先级和轮询分配，执行前核对相关状态。先实际从源端取出，再写入目标，按实际接受量结算。部分接收或拒收时，未送达物品退回源端或进入示例缓冲。
- 在端口权限和传输额度允许时合并读写。为每轮设置扫描和搬运预算。原版箱子只在本轮复用读到的库存状态，满箱按间隔重试。

## 验收

正式验收环境为**网易开发工作台的本地测试世界**。在同一存档加载前置包和两个独立示例包，并按文档完成接入。

| 验收项 | 通过条件 |
| --- | --- |
| 跨组件互通 | 示例 A 和 B 能通过公开接口交换 FE、物品和流体。模拟查询前后储量一致，实际收发量与库存变化一致 |
| 方块供电 | 发电机能向电池和耗电设备供电，断开后停止，按面权限正确 |
| 原版箱子 | 普通单箱和双箱可通过统一物品接口与自定义设备双向搬运。双箱从两半接入时，共享槽位和容量只计算一次 |
| 流体 | 水和岩浆均可在机器与储罐之间传输。类型不兼容、满罐和空罐时返回正确结果 |
| 多端搬运 | 一对多可按目标容量分发，多对一可按共享容量分配，多对多遵守过滤和调度顺序。同一槽位通过多个面访问时仍只按一份库存计算 |
| 部分失败 | 目标满载、拒收或少收时，源端、目标端和示例缓冲的物品总量守恒，物品自定义数据保留 |
| 存档与区块 | 保存并重进后恢复储量。区块卸载期间相关端口不可用，重新加载后可恢复操作 |
| 性能记录 | 分别记录正常接收、部分接收、持续满箱时每轮的槽位读取、写入和耗时。记录多条路线指向同一满箱时的重试行为 |

联机房间和网易网络服留待后续验收。具体开发工作台与游戏版本，以及性能基线，随首次实机验收记录。
